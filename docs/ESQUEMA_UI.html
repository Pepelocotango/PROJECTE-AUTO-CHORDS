Coordenades unificades: TOTS els elements (clips, cursor, grid, regle, ona, guia, loop) es posicionen amb x = _x_offset + (t − _view_left) × _pps → tot queda alineat amb zoom i pan. L'escena és de la mida de la viewport.

Esquema de color dels clips: seleccionat = vora groga gruixuda (#ffd166) · actiu (el que sona) = fons clar (#dce8ff) · normal = #2e3844. Les seccions fan servir una paleta pròpia (#3a4655 → #8996aa).
